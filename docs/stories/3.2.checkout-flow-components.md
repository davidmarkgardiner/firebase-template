# Story 3.2: Checkout Flow Components

## Story
**As a** customer ready to purchase Honduras coffee,
**I want** a streamlined checkout process with secure payment options,
**so that** I can complete my purchase quickly and confidently.

6. Order summary sidebar with item details and totals
7. Shipping method selection with cost calculation
8. Order confirmation page with receipt details
9. Email confirmation with order details and tracking
10. Form validation with real-time feedback
11. Mobile-optimized checkout experience
12. Loading states and error handling throughout
13. Order recovery for failed payments

// Payment Elements setup
import { loadStripe } from '@stripe/stripe-js'

const stripePromise = loadStripe(process.env.NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY!)

// Payment Intent creation
const createPaymentIntent = async (orderData: CheckoutState) => {
  const response = await fetch('/api/stripe/create-payment-intent', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      amount: calculateTotal(orderData),
      currency: 'eur',
      shipping: orderData.shippingAddress,
      metadata: { orderItems: JSON.stringify(orderData.items) }
    })
  })
  return response.json()
}

### EU Shipping Integration
```typescript
interface ShippingMethod {
  id: string
  name: string
  description: string
  price: number
  estimatedDays: string
  carrier: string
}

const shippingMethods = {
  EU: [
    { id: 'standard', name: 'Standard Delivery', price: 5.99, estimatedDays: '3-5', carrier: 'DHL' },
    { id: 'express', name: 'Express Delivery', price: 12.99, estimatedDays: '1-2', carrier: 'DHL Express' },
    { id: 'free', name: 'Free Delivery', price: 0, estimatedDays: '5-7', carrier: 'PostNL' }
  ]
}

function calculateShipping(address: Address, cartTotal: number): ShippingMethod[] {
  // Free shipping over €50
  if (cartTotal >= 50) {
    return shippingMethods.EU.filter(method => method.id !== 'free')
  }
  return shippingMethods.EU
}
```

  const order = await supabase
