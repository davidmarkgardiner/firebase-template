# Story 1.1: Setup shadcn/ui and Core Layout Components

## Status
Draft

## Story
**As a** developer building the Honduras Coffee e-commerce platform,
**I want** to setup shadcn/ui with claymorphism theme and create core layout components,
**so that** we have a consistent, premium design foundation for all subsequent components.

## Acceptance Criteria

1. shadcn/ui is properly configured with TypeScript and Tailwind CSS
2. Claymorphism theme is implemented with custom CSS variables and component variants
3. Core layout components are created: Header, Footer, MainLayout
4. Navigation component with cart counter and user authentication states
5. Responsive design works on mobile, tablet, and desktop
6. All components follow TypeScript strict mode with proper interfaces
7. Components are accessible (WCAG 2.1 AA compliance)
8. Theme switching (light/dark) is implemented if needed for claymorphism

## Dev Notes

### Tech Stack Context
Based on the PRD, this project uses:
- **Frontend**: Next.js 14+ with App Router, TypeScript (strict mode), Tailwind CSS, shadcn/ui
- **Styling**: Claymorphism theme with muted, earthy color palette
- **Development**: TypeScript strict mode, no `any` types allowed

### Component Patterns
All components must follow this exact pattern:
```tsx
interface ComponentNameProps {
  prop1: string
  prop2?: number
  onAction?: () => void
}

export default function ComponentName({ prop1, prop2, onAction }: ComponentNameProps): JSX.Element {
  // Component logic here
  return (
    <div className="tailwind-classes">
      {/* JSX here */}
    </div>
  )
}
```

### File Organization
Components should be placed in:
- `src/components/ui/` - shadcn/ui auto-generated components
- `src/components/layout/` - Layout components (Header, Footer, MainLayout)
- Each component gets its own file: `ComponentName.tsx`

### Claymorphism Design Requirements
The claymorphism theme should provide:
- Soft, organic shapes with subtle shadows
- Muted, earthy color palette (perfect for coffee branding)
- Smooth transitions and micro-animations
- Card-based layouts with depth
- Premium, artisanal feel

Key visual elements:
- Soft shadows: `box-shadow: 0 8px 32px rgba(31, 38, 135, 0.37)`
- Rounded corners: `border-radius: 16px`
- Semi-transparent backgrounds
- Earthy colors: browns, creams, warm grays

### Project Structure Context
Based on PRD, the expected file structure:
```
src/
├── components/
│   ├── ui/              # shadcn/ui components (auto-generated)
│   └── layout/          # Layout and navigation components
├── app/
│   ├── layout.tsx       # Root layout using MainLayout
│   └── page.tsx         # Homepage
└── styles/
    └── globals.css      # Global styles and Tailwind imports
```
