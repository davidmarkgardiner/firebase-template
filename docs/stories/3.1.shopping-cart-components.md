# Story 3.1: Shopping Cart Components

## Status
Draft

## Story
**As a** customer shopping for Honduras coffee,
**I want** a seamless shopping cart experience with easy item management,
**so that** I can review my selections and proceed to checkout efficiently.

## Acceptance Criteria

1. Cart drawer/sidebar that slides out from the header cart icon
2. Cart item display with product image, name, variant details, and price
3. Quantity adjustment controls with real-time price updates
4. Remove item functionality with confirmation
5. Cart total calculation including subtotal and estimated shipping
6. Empty cart state with suggested products
7. Persistent cart storage (localStorage + database for logged-in users)
8. Cart item count badge in header navigation
9. Quick add to cart from product cards with success feedback
10. Cart page for detailed review before checkout
11. Mobile-optimized cart interface
12. Loading states for cart operations

### Cart State Management (Zustand)
```typescript
interface CartItem {
  id: string
  productId: string
  variantId: string
  productName: string
  productImage: string
  variant: {
    format: 'whole_bean' | 'ground'
    grindType?: string
    weight: number
    price: number
  }
  quantity: number
  subscription?: {
    frequency: 'weekly' | 'biweekly' | 'monthly'
    discount: number
  }
}

interface CartState {
  items: CartItem[]
  isOpen: boolean
  isLoading: boolean
  addItem: (item: CartItem) => void
  updateQuantity: (id: string, quantity: number) => void
  removeItem: (id: string) => void
  clearCart: () => void
  openCart: () => void
  closeCart: () => void
  calculateTotals: () => CartTotals
}

interface CartTotals {
  subtotal: number
  shipping: number
  tax: number
  total: number
  itemCount: number
}
```

### Pricing and Calculations
```typescript
function calculateShipping(items: CartItem[], country: string): number {
  // EU shipping logic
  const totalWeight = items.reduce((sum, item) => sum + (item.variant.weight * item.quantity), 0)
  return totalWeight > 1000 ? 0 : 5.99 // Free shipping over 1kg
}

function calculateTax(subtotal: number, country: string): number {
  // EU VAT rates by country
  const vatRates = { DE: 0.19, FR: 0.20, ES: 0.21, /* ... */ }
  return subtotal * (vatRates[country] || 0)
}
```
