# Story 2.2: Individual Product Pages

## Status
Draft

## Story
**As a** coffee enthusiast interested in a specific Honduras coffee,
**I want** detailed product pages with comprehensive information and purchasing options,
**so that** I can make informed decisions and easily add products to my cart.

## Acceptance Criteria

1. Product hero section with high-quality images and key details
2. Product variants selection (whole bean/ground, grind types, sizes)
3. Detailed origin story and farm information
4. Interactive tasting notes visualization
5. Brewing recommendations with equipment suggestions
6. Add to cart functionality with quantity selection
7. Subscription toggle for recurring deliveries
8. Customer reviews and ratings section
9. Related products recommendations
10. Stock availability and shipping information
11. Social sharing buttons
12. SEO optimization with structured data
13. Mobile-optimized layout with swipe gestures

## Dev Notes

### Page Route Structure
```
/products/[slug] - Dynamic product pages
Example: /products/honduran-estate-reserve-250g
```

### Component Architecture
```
src/app/(shop)/products/[slug]/
├── page.tsx                    # Product page
├── loading.tsx                 # Loading state
├── not-found.tsx              # 404 state
└── components/
    ├── ProductHero.tsx
    ├── VariantSelector.tsx
    ├── OriginStory.tsx
    ├── TastingNotes.tsx
    ├── BrewingGuide.tsx
    ├── AddToCart.tsx
    ├── ReviewsSection.tsx
    └── RelatedProducts.tsx
```

### Product Data Structure
```typescript
interface ProductPage {
  product: Product
  variants: ProductVariant[]
  reviews: Review[]
  relatedProducts: Product[]
  farmInfo: {
    name: string
    location: { lat: number, lng: number }
    elevation: number
    farmer: string
    story: string
    images: string[]
  }
  brewingGuide: {
    method: string
    grindSize: string
    ratio: string
    temperature: string
    time: string
  }[]
}
```

### Variant Selection Logic
```typescript
interface VariantSelection {
  format: 'whole_bean' | 'ground'
  grindType?: 'espresso' | 'filter' | 'french_press' | 'moka'
  weight: 250 | 500 | 1000 // grams
  quantity: number
}

// Dynamic pricing based on selection
function calculatePrice(variant: ProductVariant, quantity: number): number
```

### Tasting Notes Visualization
- **Format**: Interactive radar chart with 6-8 flavor dimensions
- **Dimensions**: Acidity, Body, Sweetness, Bitterness, Aroma, Aftertaste
- **Implementation**: Custom SVG component or Chart.js integration
- **Mobile**: Simplified tag-based display

### Subscription Integration
```typescript
interface SubscriptionOption {
  enabled: boolean
  frequency: 'weekly' | 'biweekly' | 'monthly'
  discount: number // percentage
  nextDelivery: Date
}
```

### Reviews System
- **Rating**: 5-star system with half-star support
- **Verification**: Verified purchase badges
- **Moderation**: Admin approval required
- **Sorting**: Most helpful, newest, highest/lowest rating

### SEO Implementation
```typescript
// Dynamic metadata for each product
export async function generateMetadata({ params }): Promise<Metadata> {
  const product = await getProduct(params.slug)
  return {
    title: `${product.name} - Honduras Mountain Coffee`,
    description: `${product.description.substring(0, 160)}...`,
    openGraph: {
      title: product.name,
      description: product.description,
      images: [product.images[0]],
      type: 'product'
    },
    // JSON-LD structured data for products
    other: {
      'structured-data': JSON.stringify({
        '@context': 'https://schema.org',
        '@type': 'Product',
        name: product.name,
        // ... full product schema
      })
    }
  }
}
```

### Mobile Optimization
- **Image Gallery**: Swipe gestures for image navigation
- **Sticky Add to Cart**: Fixed bottom bar on mobile
- **Accordion Sections**: Collapsible content areas
- **Touch Targets**: Minimum 44px for all interactive elements

### Performance Considerations
- **Image Optimization**: Next.js Image with priority loading for hero
- **Code Splitting**: Dynamic imports for heavy components (charts, maps)
- **Caching**: Static generation for product pages with ISR
- **Lazy Loading**: Below-fold components and images
