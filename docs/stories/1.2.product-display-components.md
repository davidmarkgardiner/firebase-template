# Story 1.2: Product Display Components

## Status
Draft

## Story
**As a** customer browsing the Honduras Coffee website,
**I want** to see beautifully designed product cards and detailed product pages,
**so that** I can easily discover and learn about the specialty coffee offerings.

## Acceptance Criteria

1. ProductCard component displays product image, name, price, and key details
2. ProductGrid component arranges multiple ProductCard components responsively
3. ProductDetail component shows comprehensive product information
4. Origin details section with farm, altitude, and processing information
5. Tasting notes visualization with interactive elements
6. Brewing recommendations section
7. Stock availability indicators (in stock, low stock, out of stock)
8. Related products section
9. All components follow claymorphism design theme
10. Mobile-first responsive design implemented
11. Loading states and error handling included

## Dev Notes

### Product Data Structure
Based on PRD database schema:
```typescript
interface Product {
  id: string
  name: string
  slug: string
  description: string
  origin_farm: string
  altitude: number
  processing_method: string
  tasting_notes: string[]
  roast_level: string
  harvest_date: Date
  story: string
  featured: boolean
}

interface ProductVariant {
  id: string
  product_id: string
  sku: string
  format: 'whole_bean' | 'ground'
  grind_type?: string
  weight: number // in grams
  price: number
  stock_quantity: number
  allow_backorder: boolean
}
```

### Component Architecture
```
src/components/shop/
├── ProductCard.tsx
├── ProductGrid.tsx
├── ProductDetail.tsx
├── StockBadge.tsx
├── TastingNotes.tsx
└── RelatedProducts.tsx
```

### Claymorphism Design Specifications
- **Product Cards**: Soft elevated cards with subtle shadows
- **Color Palette**: Warm coffee browns (#8B4513, #D2691E), cream (#F5F5DC)
- **Hover Effects**: Gentle lift animation with increased shadow
- **Typography**: Elegant serif for product names, sans-serif for details
- **Spacing**: Generous white space for premium feel

### Integration Points
- **Images**: Supabase Storage for product images
- **Data**: Supabase database via product queries
- **SEO**: Next.js metadata for product pages
- **Performance**: Image optimization with Next.js Image component

### File Locations
- Components: `src/components/shop/`
- Types: `src/types/product.ts`
- Utilities: `src/lib/utils/product-helpers.ts`
- Styles: Component-level Tailwind classes

## Testing

### Testing Standards
- **Framework**: React Testing Library + Jest
- **File Location**: Same directory as component with `.test.tsx` extension
- **Coverage**: Minimum 80% for all product components
- **Visual Testing**: Storybook stories for design system

### Key Test Scenarios
1. **ProductCard**: Renders product data, handles missing images, stock states
2. **ProductGrid**: Responsive layout, loading states, empty states
3. **ProductDetail**: Complete product information, tasting notes display
4. **User Interactions**: Hover effects, click events, responsive behavior
