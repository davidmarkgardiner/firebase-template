Homepage Components

  - card - Hero section container, featured product cards
  - button - CTA buttons, navigation actions
  - carousel - Featured products slideshow
  - badge - "Featured", "Limited Edition" labels
  - avatar - Customer testimonials
  - separator - Section dividers

  Navigation & Layout

  - navigation-menu - Main site navigation
  - sidebar - Admin panel navigation
  - breadcrumb - Page hierarchy navigation
  - sheet - Mobile menu drawer
  - dropdown-menu - User account menu
  - command - Search functionality

  Product Components

  - card - Product display cards
  - carousel - Product image gallery
  - tabs - Product information sections (Details, Origin, Reviews)
  - badge - Stock status, roast level indicators
  - select - Grind type, size selection
  - radio-group - Subscription vs one-time purchase
  - slider - Quantity selector
  - skeleton - Loading states

  Shopping Cart & Checkout

  - drawer - Slide-out cart
  - table - Cart items display
  - form - Checkout form with validation
  - input - Address, payment details
  - checkbox - Terms acceptance, guest checkout
  - progress - Checkout steps indicator
  - alert - Validation messages, success/error states

  Account Dashboard

  - tabs - Account sections (Orders, Subscription, Settings)
  - table - Order history
  - card - Subscription status, order summaries
  - button - Manage subscription, reorder actions
  - dialog - Edit profile, cancel subscription
  - calendar - Next delivery dates

  Admin Panel Components

  - sidebar - Admin navigation
  - table - Product list, order management, customer list
  - form - Product creation/editing
  - input - Search bars, filters
  - select - Status updates, bulk actions
  - chart - Analytics dashboard
  - alert-dialog - Delete confirmations
  - pagination - Large data sets
  - toggle - Feature toggles

  Forms & Inputs

  - form - All form containers with validation
  - input - Text inputs, email, passwords
  - textarea - Product descriptions, order notes
  - select - Dropdown selections
  - checkbox - Multiple selections, agreements
  - radio-group - Single selections
  - switch - Settings toggles

  Feedback & Status

  - sonner - Toast notifications
  - alert - Information, warnings, errors
  - progress - Upload progress, processing status
  - skeleton - Loading placeholders
  - badge - Status indicators

  Interactive Elements

  - hover-card - Product quick previews
  - tooltip - Help text, additional information
  - popover - Action menus, filters
  - collapsible - FAQ sections, product details
  - accordion - Product specifications

  Data Display

  - table - Structured data (orders, products, customers)
  - scroll-area - Long content areas
  - separator - Content dividers
  - aspect-ratio - Product images consistency
